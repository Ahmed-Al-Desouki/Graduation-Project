4️. Domain Project (WelloraHealthCareManagment.Domain)
يحتوي على: Entities, Value Objects, Enums, Aggregates, Domain events
عادةً لا يحتاج أي NuGet packages خارجية إلا لو عندك Value Objects 
أو helpers زي Newtonsoft.Json أو System.Text.Json، لكن غالباً تسيبها نقية قدر الإمكان.
